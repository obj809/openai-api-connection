# openai-api-connection

# How to Guide: OpenAI API Connection

## Description: A quickstart guide to assist developers connect with the OpenAI API.

## Requirements
- Python 3.10+

## Build Steps

1) Create an OpenAI account

[Link text](https://openai.com/api/)

2) Create an API key 

Once logged in:
[Link text](https://platform.openai.com/api-keys)

3) Clone this repo

```bash
git clone https://github.com/obj809/openai-api-connection
cd openai-api-connection
```

4) Create venv

```bash
python -m venv venv
```

5) Activate venv

macOS / Linux
```bash
source venv/bin/activate
```

Windows (PowerShell)
```powershell
venv\Scripts\Activate.ps1
```

5) Install requirements.txt 

```bash
pip install -r requirements.txt
```

(Optional) Edit the prompt value in prompts.py

6) Run main.py

```bash
python main.py
```
